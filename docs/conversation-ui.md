# 会话呈现与子智能体侧栏

会话按用户回合组织。中间工具与思考默认收起，最后一条回答在折叠区域外显示。折叠状态由回合 ID 保存，虚拟滚动卸载组件后仍可恢复。输出平滑只影响呈现文本；搜索、停止、异常、后台页面与减少动态效果模式会直接显示已有内容。

## 子智能体

- `subAgents` 保存真实子任务的最新状态，`subAgentEvents` 单独保存开始、完成、失败等快照。事件按子任务、指令和状态去重，不以角色名称判断任务身份。
- 生命周期记录保留在收到事件时所属的消息位置；折叠工作过程仍显示这些记录，展开后不会重复显示。正文不因插入事件被拆成多个 Markdown 实例。
- 图标按研究、编码、测试和通用角色区分。点击状态行或展开列表中的子任务打开右侧只读会话。
- 只读面板通过父会话作用域调用 `subagent.status` 和 `session.get`，读取真实子会话。`subagent_progress` 的可选 `kind`、`delta` 与 `childSessionId` 传递实时正文、思考、模型及重试状态，不混入父会话输出。
- 关闭面板释放事件订阅与刷新定时器；切换任务后丢弃旧请求结果。内部子会话保留在数据库中，但不出现在用户任务列表中。
- 生命周期通知来源于运行时事件。旧版本历史没有保存这些通知时，保留可用的任务结果，不推测通知发生时间。

## 自动标题

新会话由独立的小型模型请求总结首轮目标，提取第一句作为标题；请求不使用工具、不写入聊天记录，也不阻塞主回答的终止响应。生成期间侧栏和标题栏显示骨架，失败或断连后结束加载。

数据库 `title_source` 区分待生成、原输入、AI 总结和手动名称。自动写入采用条件更新，无法覆盖手动改名或已生成的标题，也不会重新创建已删除会话、改变会话排序时间。迁移时将已有标题保留为手动名称。

## 右键菜单

任务与项目菜单使用统一的 `ContextMenu`。浮层挂在页面根节点，按光标或按钮位置定位并避让窗口边缘，不改变侧栏滚动容器。支持分组、禁用项、危险操作、子菜单、方向键、Home/End、Enter/Escape 和焦点恢复。

菜单仅提供已接通的动作。项目删除仍明确表示删除项目注册与会话，保留原来的确认流程；不将它改名为仅移除项目。复制会话会在需要时先读取完整历史，分叉复用现有 `session.fork`。
