Run a command that needs incremental output, stdin, a pseudo terminal, or background execution. Start returns immediately with sessionId. Read using that ID and the returned cursor; use bounded wait_ms instead of busy polling. Output is paged: continue reading while hasMore is true, even after status is exited. endCursor is the total output position. Write sends exact stdin text, including any newline. EOF closes input. terminate kills the process tree; close additionally releases the session handle. Sessions belong to the current conversation and survive subsequent turns while the runtime stays running. Use pty for tools that require a real terminal. Report nonzero exit codes and truncated output. This tool grants no permissions beyond the parent task.
