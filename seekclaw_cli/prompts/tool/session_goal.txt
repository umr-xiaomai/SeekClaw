Manage a persistent goal for the current conversation. Use create only if the user explicitly requests a long-running goal. Store the requested outcome and verifiable completion criteria. Use progress at meaningful checkpoints to record what was completed, relevant paths and what remains. Use pause with a concrete reason if you need the user to act or provide information before work can continue. Use complete with verification evidence only after all criteria have been fulfilled, then summarize the outcome. The runtime records completion after the final response and any configured workspace verification. An ordinary plan or a single-turn answer does not require creating a goal.
