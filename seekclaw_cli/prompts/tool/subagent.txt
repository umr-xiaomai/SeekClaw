Manage persistent specialized sub-agents. spawn returns immediately with a durable task ID and session ID. Provide an optional short display name (e.g. 'Demo explainer') when spawning to label each sub-agent in the UI. Use status or bounded wait, send/followup to guide or resume an existing task, or cancel one task without stopping others. Guidance to a running child is queued and applied at its next model/tool boundary, without interrupting its current operation; instructionQueued acknowledges enqueueing, not completion. Idle or interrupted tasks resume in the same child session. Use list to rediscover tasks in this conversation. Set worktree for independent changes in a Git checkout. Give every agent a concrete bounded assignment and collect results before relying on them. Spawn inherits a bounded selection of parent user requirements and relevant results, not the entire transcript or private reasoning. Use context for concise additional background, or inherit_context=false to start without parent history. Background agents inherit the parent's permissions and network ceiling. A restarted runtime can resume interrupted tasks with send; it cannot resurrect an already terminated process. Never assume a running task is complete.
