Manage persistent specialized sub-agents. spawn returns immediately with a durable task ID and session ID. Use status or bounded wait, send a follow-up instruction after completion/interruption, or cancel one task without stopping others. Use list to rediscover tasks in this conversation. Set worktree for independent changes in a Git checkout. Give every agent a concrete bounded assignment and collect results before relying on them. Background agents inherit the parent's permissions and network ceiling. A restarted runtime can resume interrupted tasks with send; it cannot resurrect an already terminated process. Never assume a running task is complete.
