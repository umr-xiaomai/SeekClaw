# 2026-10-24

## 新增：跨对话记忆（类似 Codex）
- 需求：给 SeekClaw 增加跨对话记忆，会话仍按工作区隔离，不复制完整旧聊天。
- 方案：Runtime 层新增用户级记忆；成功 turn 后用模型提炼少量长期事实；后续新 Session 通过 system prompt 召回；默认关闭。
- 关键文件：
  - 新增 `seekclaw_runtime/Memory/CrossSessionMemory.cs`、`CrossSessionMemoryStore.cs`（SQLite `cross_session_memories`，content_key SHA256 去重，`DropSchema` 同步清理）。
  - 新增 `seekclaw_runtime/Agents/Agent.Memory.cs`（提炼/解析/敏感信息过滤，只输入当前用户消息与最终回答，失败不影响主 turn）。
  - 新增提示词 `seekclaw_cli/prompts/builtin/memory_extract.txt`、`cross_session_memory.txt`。
  - 修改 `Agent.Prompting.cs` 注入 `cross_session_memory`；`Agent.cs` 在成功、非取消、非子代理、非定时任务时提炼。
  - `SeekClawConfig.Agent.EnableCrossSessionMemory` 默认 false；Daemon 新增 `memory.list/delete/clear` 与 `advanced.get/set` 开关；Desktop 高级设置新增开关与条目管理。
- 验证：`dotnet test seekclaw_tests` 255 通过；桌面端 `vue-tsc` 与 `vitest` 86 通过。
